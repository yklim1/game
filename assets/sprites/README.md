# assets/sprites

스프라이트(투명 PNG)를 넣는 곳. **규격과 체크리스트는 `docs/ART_ASSET_SPEC.md` 를 따른다.**

```
player/     플레이어
animals/    적(동물)
abilities/  투사체·근접 잔상·장판/오라
pickups/    정수 젬·먹이
fx/         사망 조각 등 이펙트
ui/icons/   변이·능력 아이콘 (표시 UI 미구현 — 아직 만들지 않는다)
```

파일명은 데이터의 `id` 와 같게 짓는다(`spore_ant.png` ↔ `data/animals/spore_ant.tres`).
PNG를 넣는 것만으로는 반영되지 않는다. 해당 `.tres`(또는 씬)의 텍스처 필드에 지정해야 한다.
필드가 비어 있으면 플레이스홀더(`_placeholder.svg` + 색)로 계속 동작하므로 한 종류씩 교체해도 된다.

`_placeholder.svg` 는 아트가 없는 대상에 물리는 **폴백 전용 에셋**이다(게임 아트가 아니다).
배경이 투명하고 전부 흰색인 "링 + X" 표식이라, 데이터 색을 곱하면 그 색으로 나오고 실제 아트로 오인되지 않는다.
프로젝트 아이콘(`res://icon.svg`)과는 별개 파일이므로 한쪽을 바꿔도 다른 쪽에 영향이 없다. 게임 아트를 여기에 넣지 말 것.
