# PLAN.md — 단계별 개발 계획

> 대상: **Feral Bloom**(가제) · 2D 로그라이트 서바이버 (동물 진화/변이 테마) · Godot 4.7.1 / GDScript
> 짝 문서: [`DESIGN.md`](./DESIGN.md) · 저장소: `D:\work\game`
> 원칙: **재미 우선 검증** → 코어 루프가 재미없으면 폴리시 전에 방향 전환.

---

## 0. 이 계획서 사용법

- 각 Phase는 **목표 → 체크리스트(TODO) → 완료 기준(DoD) → 난이도 → Cursor 지시 순서**로 구성.
- **DoD를 통과하기 전 다음 Phase로 넘어가지 않는다**(스코프 크립 방지).
- Cursor에게 시킬 때는 항상 **"DESIGN.md의 X 섹션 스키마대로"** 라고 근거를 명시하면 결과 품질이 올라간다.
- 난이도: ★(쉬움) ~ ★★★★★(어려움).

### 마일스톤 / 버전 태그

| 버전 | 내용 | 대응 Phase | 의미 |
|------|------|-----------|------|
| **v0.1** | 코어 루프(이동+자동공격+적+사망) 검증 | Phase 1 | **재미 판정 게이트** |

| **v0.4** | 메타 프로그레션 + 타격감/폴리시 + 저장 | Phase 4 | "게임다움" 완성 |

## Phase 1 — 코어 루프 (v0.1) ✅ (구현 완료 · 재미 판정은 사람이 직접)

**목표(1줄)**: 이동+자동공격+적 스폰+사망까지 "10분 붙잡을 만한" 코어 루프를 만든다.

### 체크리스트
- [x] 오토로드 최소 세팅: `EventBus`(시그널 버스), `RunState`(HP/XP/시간)
- [x] `Player.tscn`(작은 동물): 8방향 이동, HP, 무적 프레임, 피격 처리
- [x] `AbilityManager` + 능력 1종(발톱/가시): 최근접 적 자동 조준·자동 발동(투사체/근접)
- [x] `Attack`(투사체/스윙): 이동·충돌·데미지·수명(우선 풀링 없이 동작 확인 → 곧 풀링 전환)
- [x] `Animal`(적 1종): 스폰 후 플레이어 추격, 접촉 피해, 사망 시 `animal_died` 시그널
- [x] `AnimalSpawner`: 화면 밖에서 일정 간격 스폰(수량 점증)
- [x] `Essence`(정수 젬) 픽업: 동물 사망 시 드롭 → 픽업 반경 흡수 → XP 증가 → 진화(임시: 즉시 +데미지/+속도) *(Phase 2에서 완료)*
- [x] `HUD`: HP 바, 경과 시간, 레벨/XP
- [x] 사망 처리 → 임시 결과 화면(생존 시간·처치 수) → 재시작
- [x] **오브젝트 풀링** 도입(동물·공격·정수) — 스폰량 늘려 프레임 확인

### 완료 기준 (DoD)
- 실제로 5~10분 플레이 가능, 적이 계속 밀려오고, 레벨업으로 강해지는 상승감이 체감됨.
- 적/투사체 수백 개 상황에서 60fps 유지(풀링 적용 후).
- **재미 판정**: "한 판 더" 하고 싶은가? → NO면 조작감/타격감/스폰 곡선부터 손본다(방향 전환 트리거).

### 난이도: ★★★

### Cursor 지시 순서 (실전)
1. "`scripts/autoload/event_bus.gd`에 전역 시그널(`animal_died(pos, animal_data)`, `player_evolved(level)`, `player_died`)을 만들고 프로젝트 오토로드로 등록해줘."
2. "`Player.tscn`과 `player.gd`: CharacterBody2D 기반 8방향 이동, export로 move_speed/max_hp, 피격 시 i-frame. DESIGN.md 4.1 참고."
3. "최근접 적을 찾아 발동하는 `AbilityManager`와 `Attack`(투사체/스윙)을 만들어줘. 조준=최근접."
4. "`Animal`(CharacterBody2D): 플레이어 추격 + 접촉 피해 + HP. 죽으면 EventBus.animal_died emit."
5. "`AnimalSpawner`: 화면 밖 원형 스폰, 시간에 따라 간격 단축."
6. "정수(젬) 드롭·흡수·XP·진화(임시 스탯업) 연결. HUD 추가."
7. "동물/공격/정수를 **오브젝트 풀**로 바꿔줘. 재사용 시 상태 초기화 주의."

> **팁**: 1~7을 한 번에 시키지 말고 **하나씩 실행→플레이 확인**. 각 단계 후 직접 F5로 감(感)을 본다.

- [x] `MutationData` Resource + 변이 풀(.tres) (STAT/NEW_ABILITY/ABILITY_UP) — 24종

- [ ] (선택) 상점 슬롯 확장 구매 — **추후 과제**(현재 슬롯 6 고정)

- 계통 시너지 발동 시 명확한 피드백(아이콘/텍스트).

### 난이도: ★★★★

### Cursor 지시 순서
1. "`MutationData.gd`(DESIGN.md 5.2) + 변이 .tres 12~20개."
2. "`MutationCard` UI: 풀에서 가중치로 3개 뽑아 제시, 선택 시 payload 적용, get_tree().paused 처리."

## 부록 B — 개발 습관 (1인 · Cursor)

- **작게 시키고 자주 실행**: 한 지시 = 한 기능. 매 단계 F5로 확인.

- **재미 게이트 존중**: v0.1에서 안 재밌으면 멈추고 조정. 폴리시로 재미를 못 만든다.
